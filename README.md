# MATLAB-Based Second-Hand Marketplace

A second-hand marketplace application developed using MATLAB that allows users to buy and sell used products through a simple graphical interface.

## Overview

This project simulates an online marketplace where users can:

- Browse available products
- Add items for sale
- Search for products
- Manage listings
- View product details

The application is built using MATLAB and demonstrates GUI design, data handling, and marketplace system logic.

## Features

- User-friendly MATLAB GUI
- Add new products
- Display available marketplace items
- Product search functionality
- Product management system
- Buy and sell workflow simulation
- Organized marketplace interface


## How to Run
Download or clone the repository:
git clone https://github.com/menal00/Building-an-Online-Game-Store-Website.git
Open the project folder.
Open index.html in your browser.

No server or installation is required.
